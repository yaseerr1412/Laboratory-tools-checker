Inventory Reset / Replacement

Use with care. These actions are intended for replacing your current tool inventory. Your saved student database is not deleted.

Clear Tools Only: removes all tool records but preserves students and transaction history. Clear Tools + Tool Transaction History: removes the tool inventory and all borrowing/issue/return records, while preserving students. Both require two confirmations.

Replace Inventory from Excel / CSV

Select your new inventory file, then click Replace. For Excel files, ALL worksheets are read automatically. The app validates all sheets first, asks for two confirmations, clears the existing tool inventory, and imports the new list in one operation. Student records are preserved.

Import Tool Inventory from Excel / CSV

Accepts .xlsx, .xls, or .csv. For Excel workbooks, ALL worksheets are read automatically, so you can keep several tool lists/sections/categories in one workbook. Recommended columns: Tool ID, Tool Name, Category, Type, Part Number, Serial Number(s), Quantity, Qty Damaged, Qty Lost, Qty Maintenance, Brand / Model, Location, Remarks.

If Tool ID already exists, the import updates that record instead of duplicating it.
